The default output of a data science team is a slide deck. A static artifact, presented once, debated once, archived once. It is the wrong format for the thing the business actually needs: a live tool the team can interrogate themselves.

## The Deck Tax

Every deck is a translation of a model into a frozen narrative. The translation costs days. The decision it supports is made in minutes. And the next time the same question comes up — with new data, a new region, a new SKU — the translation has to be done again.

> "A deck is a frozen answer. A product is a live question."

Interactive products invert the cost curve. Build once, query forever. The data scientist's leverage moves from "answer the question this week" to "build the surface where the team can answer their own question, every week."
